# 議題分流標籤

工程技能使用以下五種標準角色。本儲存庫沿用相同的實際標籤字串。

| 技能中的標準角色 | 議題追蹤系統的標籤 | 意義 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待維護者評估 |
| `needs-info` | `needs-info` | 等待回報者補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可交由代理自主執行 |
| `ready-for-human` | `ready-for-human` | 需要由人員實作 |
| `wontfix` | `wontfix` | 不予處理 |

技能提到某個分流角色時，使用表中對應的標籤字串。日後若要配合既有標籤命名，修改第二欄即可。
